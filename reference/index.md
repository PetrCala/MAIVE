# Package index

## Main Functions

Core functions for performing meta-analysis with instrumental variables

- [`maive()`](https://petrcala.github.io/MAIVE/reference/maive.md) : R
  code for MAIVE
- [`waive()`](https://petrcala.github.io/MAIVE/reference/waive.md) :
  WAIVE: More Aggressive Correction for P-Hacking and Spurious Precision
- [`maive_from_metafor()`](https://petrcala.github.io/MAIVE/reference/maive_from_metafor.md)
  : Convert metafor objects into MAIVE input data
- [`get_funnel_plot()`](https://petrcala.github.io/MAIVE/reference/get_funnel_plot.md)
  : Draw a funnel plot (base graphics)

## Internal Functions

Internal helper functions (not typically called directly by users)
